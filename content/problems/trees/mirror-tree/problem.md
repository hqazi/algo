# Mirror the Tree

**Topic:** Binary trees · **Difficulty:** Easy

Turn a binary tree into its **mirror image**: at every node, swap the left and
right subtrees. Return the root.

## Examples

**Example 1**

```text
Input:  root = [4, 2, 7, 1, 3, 6, 9]
Output: [4, 7, 2, 9, 6, 3, 1]
```

**Example 2**

```text
Input:  root = [2, 1]
Output: [2, null, 1]
```

## Constraints

- 0 <= number of nodes <= 10^4

## Notes

Trees are passed in and returned as nodes; the examples write a tree as a list in level order, with `null` for a missing child.
