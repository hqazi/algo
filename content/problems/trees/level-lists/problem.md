# Level by Level

**Topic:** Binary trees · **Difficulty:** Medium

Return the values of a binary tree **level by level**, from the root down, and
left to right within each level.

## Examples

**Example 1**

```text
Input:  root = [3, 9, 20, null, null, 15, 7]
Output: [[3], [9, 20], [15, 7]]
```

**Example 2**

```text
Input:  root = []
Output: []
```

## Constraints

- 0 <= number of nodes <= 10^4

## Notes

Trees are passed in as nodes; the examples write a tree as a list in level order, with `null` for a missing child.
