# Reverse the Chain

**Topic:** Linked lists · **Difficulty:** Easy

Given the head of a singly linked list, reverse the list **by rewiring the `next`
pointers** and return the new head. Do not build a new list.

## Examples

**Example 1**

```text
Input:  head = [1, 2, 3, 4, 5]
Output: [5, 4, 3, 2, 1]
```

**Example 2**

```text
Input:  head = []
Output: []
```

## Constraints

- 0 <= length <= 10^5
- -10^5 <= node.val <= 10^5

## Notes

Linked lists are passed in and returned as nodes; the examples write a linked list as the list of its values from the head (`[]` for an empty one).
