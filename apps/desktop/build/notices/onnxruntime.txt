ONNX Runtime

Read aloud (T38) runs the Kokoro voice model with ONNX Runtime's Node.js
binding: the `onnxruntime-node` and `onnxruntime-common` npm packages
(1.31.1), shipped unmodified in the app's resources (onnxruntime-node/),
with the native library for this platform only.
